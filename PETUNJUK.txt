CARA MEMASANG
1. Buat cadangan sudah dilakukan sebelumnya; jangan hapus WASHUP_BACKUP.
2. Ekstrak isi ZIP ini LANGSUNG ke folder: C:\KULIAH\semester3\PBL\WASHUP
3. Jika Windows menanyakan penggantian file, izinkan penggantian index.html dan css/style.css.
4. Arsip ini tidak berisi folder .git dan tidak mengganti js/app.js, sehingga metadata Git dan perubahan JavaScript lokal tetap dipertahankan.
5. Buka index.html di browser dan uji tombol Login WASHUP serta halaman login/dashboard.
6. Jangan commit/push sebelum pengujian selesai.
